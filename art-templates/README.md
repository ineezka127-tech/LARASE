# 🎨 그림 밑그림 틀

직접 그린 옷·장비·몬스터를 앱에 넣을 때 쓰는 밑그림이에요.

## 옷·장비 (01~11번)
1. 그리고 싶은 칸의 밑그림(예: `04-hat.png`)을 그림 앱에서 엽니다. 이비스페인트, 스케치북, Krita 등에서 열 수 있어요.
2. **새 레이어**를 만들고, **점선 안에** 그립니다.
   - 회색 몸과 연한 예시는 크기와 위치를 맞추는 참고용이에요.
3. 다 그리면 **밑그림 레이어를 끄고**, **배경이 투명한 PNG**로 저장해요.
   - 판 크기 800 × 1096은 그대로 둡니다. 자르지 마세요.
4. 그림 파일과 함께 이름·칸·원하는 능력치를 알려 주세요.
   - 예: "불꽃 투구, 모자 칸, 방어 +2, 300코인"

| 파일 | 칸 |
|---|---|
| 00-overview.png | 모든 칸 위치 한눈에 보기 |
| 01-top / 02-bottom / 03-shoes | 상의 / 하의 / 신발 |
| 04-hat / 05-armor | 모자·투구 / 갑옷 |
| 06-held / 07-shield | 무기·소품(오른손) / 방패(왼손) |
| 08-acc / 09-glasses | 장신구(목걸이·날개) / 안경 |
| 10-bg / 11-pet | 배경(판 전체) / 펫 |

💡 굵은 검정 테두리에 동글동글하게 그리면 지금 캐릭터와 잘 어울려요. 종이에 그려서 사진을 보내도 괜찮아요.

## 몬스터·보스 (20번)
- 800 × 800 판의 점선 원 안에 그리고, 발은 그림자 위에 오게 해요.
- 전투 화면에서 몬스터는 왼쪽, 내 캐릭터는 오른쪽에 서요. 그래서 몬스터가 **오른쪽을 바라보게** 그려요.
- "숲 월드 보스", "동굴 일반 몬스터 2"처럼 어디에 넣을지 알려 주세요.
