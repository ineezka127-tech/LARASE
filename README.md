# 📚 복습 교실

특수학급 학생들이 수업 내용을 복습하고, 퀴즈를 풀며 경험치·레벨을 모으는 웹앱입니다.

- **선생님**: 아이캔노트 판서·PDF를 올리고, 클로드(claude.ai)로 만든 요약·낱말 카드·퀴즈를 붙여넣어 공개합니다.
- **학생**: 갤럭시탭에서 로그인해 복습 자료를 보고 퀴즈를 풀며 경험치를 얻습니다.
- **수업 모드**: 교실 TV에 띄워 정리 단계에서 함께 문제를 풉니다.

무료 서비스만 사용합니다: **GitHub Pages**(웹앱)와 **Supabase**(로그인·데이터·판서 이미지).

## 1. Supabase 설정 (처음 한 번)

1. [supabase.com](https://supabase.com) → **New project**
   - Name: `bokseup` (자유)
   - Database Password: 아무거나 정해서 적어 두기
   - Region: **Northeast Asia (Seoul)**
2. 프로젝트가 만들어지면 왼쪽 메뉴 **SQL Editor** → **New query**
   - 이 저장소의 [`supabase/schema.sql`](supabase/schema.sql) 내용을 **전부 복사해 붙여넣고 Run**
   - "destructive operation" 경고가 나오면 **Run this query**를 눌러도 됩니다. (규칙을 다시 만들기 위한 `drop`이라 데이터는 지워지지 않아요.)
   - 아래에 `Success. No rows returned`가 나오면 성공
3. **Authentication → Sign In / Providers → Email**
   - **Confirm email** 을 **끄고** Save
   - (학생 계정은 실제 메일이 없어서 메일 확인을 끄는 거예요.)
4. **Project Settings → API Keys** (또는 화면 위쪽 **Connect** 버튼)
   - **Project URL** (예: `https://abcd1234.supabase.co`)
   - **anon public key** 또는 **publishable key** (`eyJ...` 또는 `sb_publishable_...`)
   - 이 두 개를 [`config.js`](config.js)에 넣습니다.
   - ⚠️ **service_role / secret key** 는 절대 넣지 마세요.

```js
window.APP_CONFIG = {
  SUPABASE_URL: "https://abcd1234.supabase.co",
  SUPABASE_KEY: "여기에 anon 또는 publishable key",
  ...
};
```

## 2. GitHub Pages로 공개

1. GitHub 저장소의 **Settings → Pages**
2. **Source: Deploy from a branch**, **Branch: `main` / `(root)`** → Save
3. 1~2분 뒤 `https://<깃허브아이디>.github.io/<저장소이름>/` 주소가 생깁니다.
4. 갤럭시탭 크롬에서 이 주소를 열고, 메뉴 → **홈 화면에 추가**를 하면 앱처럼 쓸 수 있어요.

> 무료 GitHub Pages는 **Public 저장소**에서 작동합니다. 저장소에는 코드와 공개용 키만 있고, 학생 기록은 Supabase에 안전하게 따로 저장됩니다.

## 3. 처음 접속하기

1. 앱 주소에 접속하면 **처음 설정** 화면이 나옵니다 → 선생님 계정 만들기 (아이디 `선생님`, 비밀번호는 학생이 모르는 것으로)

4. 학생은 처음 로그인할 때 **화면에 보일 이름**과 캐릭터를 직접 고릅니다. (로그인 아이디와 별개)

## 4. 수업 자료 만들기 (클로드 Pro 사용, 추가 비용 없음)

1. **📚 수업 자료 → ➕ 새 수업 자료**
2. 아이캔노트 판서를 **PDF 또는 PNG/JPG로 저장**해서 올리기 → 학생 "판서" 탭에 보여요.
3. **📋 지시문 복사** → **claude.ai 열기** → 새 대화에 **같은 수업 자료를 첨부**하고 지시문 붙여넣기 → 보내기
4. 클로드 답변 아래 **복사** 버튼 → 앱의 붙여넣기 칸에 넣고 **가져오기**
5. 요약·문제를 검토하고 고친 뒤 **학생에게 공개하기**를 켜고 **저장**

💡 **더 편하게**: claude.ai에서 **프로젝트**를 하나 만들고(예: "복습 교실 자료 만들기"), 프로젝트 지침(Instructions)에 지시문을 붙여넣어 두세요. 그러면 다음부터는 그 프로젝트에서 **자료만 첨부하고 "만들어 줘"** 라고만 보내면 됩니다.

문제 유형: O/X · 5지선다 · 단답형 · 짝 맞추기 · 순서 맞추기 · 서술형 · 분수·수 답
(서술형은 **📝 채점** 메뉴에서 선생님이 정답/부분 정답/다시 해 보기로 채점하고 한마디를 남길 수 있어요.)

## 4-1. 수학: 분수 답 문제 (➗ 분수·수 답)

- 학생 화면에 **자연수 □ · 분자 □ / 분모 □** 칸이 나오고, **🔢 숫자판** 또는 **✏️ 펜으로 쓰기**로 답을 넣어요.
- 펜으로 쓴 숫자는 **태블릿 안에서 바로 인식**해요 (인터넷·API·추가 비용 없음). 확신이 낮으면 "혹시 7인가요?"처럼 다른 후보를 보여 줘서 눌러 고칠 수 있어요.
- 채점 방식은 문제마다 고를 수 있어요: 값만 맞으면 정답 / 대분수로 / 가분수로 / 똑같은 모양으로, 그리고 "기약분수만 정답".
  값은 맞았는데 모양이 다르면 "값은 맞았어요! 대분수로 나타내 볼까요?"라고 알려 줘요.
- 문제·보기·요약 글 속에 `{7/3}`, `{2 1/3}`처럼 쓰면 **분수 모양**으로 보이고, 읽어 주기는 "3분의 7", "2와 3분의 1"로 읽어요.
- 클로드 지시문에 분수 문제 만드는 방법이 들어 있어서, 수학 자료를 넣으면 분수 문제가 자동으로 만들어져요.
- ⚠️ 이 기능이 생기기 전에 Supabase를 설정했다면 [`supabase/update-02-fraction.sql`](supabase/update-02-fraction.sql)을 SQL Editor에서 **한 번** 실행해 주세요.

## 5. 경험치 규칙 (업데이트 6부터)

| 활동 | 경험치 | 코인 |
|---|---|---|
| 복습 자료 보기 | +4 × 반복 비율 (하루 한 번) | +1 |
| 처음 맞힌 문제 | +5 | +2 |
| 틀렸던 문제를 맞힘 (오답 극복) | +4 | +3 |
| 다른 날 다시 맞힘 | +1 | +1 |
| 도전 (틀려도) | +1 | |
| 서술형 제출 / 선생님 채점 | +2 / 정답 +5, 부분 +2 | +1 / +3 |
| 퀴즈 끝까지 · 묶음 퀴즈 끝까지 | +5 (모두 맞히면 +10) × 반복 비율 | 같은 양 |
| 오늘 첫 활동 (연속 출석) | +4 ~ +8 | +3 |
| 레벨 업 | 스탯 포인트 +1 | +20 (레벨 5·10·15…는 +70) |
| 🎲 모험: 몬스터·상자 | 일반 3+지역, 엘리트 8+2×지역, 보스 20+5×지역 | 비슷하게 + 아이템 |

- **반복 비율**: 같은 수업을 다시 복습할수록 1번째 100% → 2번째 50% → 3번째 30% → 4번째 20% → 그 뒤로는 10%. 같은 수업은 **하루 2번까지만** 보상해요. (처음 맞힌 문제의 보상은 문제마다 한 번뿐이라 줄이지 않아요.)

- 레벨 L → L+1 에 필요한 경험치: `40 × L^1.4` (5 단위 반올림), 레벨 5·10·15…로 가는 길은 ×1.2 고개 → 40, 105, 185, **335**, 380, 490, 610, 735, **1040**, 1005 … 대신 그 레벨에 오르면 코인 +50 보너스와 새 칭호
- 레벨은 내려가지 않아요. 새 규칙 전에 오른 레벨은 그대로 두었어요.
- 처음부터 다시 시작하려면: **👥 학생 → 🔄 진도 초기화** (한 명 / 전체, 코인 유지 여부 선택, 풀이 기록은 남음)
- 같은 문제를 같은 날 반복해 푸는 것으로는 경험치가 쌓이지 않습니다. 경험치는 서버에서만 계산돼요.

## 5-0. 📚 과목·주제·기간으로 묶기 / 🔁 다양한 퀴즈

- **📚 수업 자료 → 과목·주제 관리**: 과목 추가·이름 바꾸기·순서·숨기기, 과목마다 **주제(제재)** 만들기
- 수업 자료 편집에서 **과목**과 **주제**를 고르면, 학생·선생님 화면에서 **과목별 / 주제별 / 날짜별**로 묶여 보여요. 기간(이번 주, 지난주, 이번 달, 기간 정하기)도 고를 수 있어요.
- 학생은 **🎯 주제 전체 퀴즈**, **🧠 이 주·이 기간·과목 총정리 퀴즈**를 풀 수 있어요 (서술형 제외, 10문제).
- 퀴즈는 매번 **새로 뽑아요**: 지난번에 틀린 문제 → 안 푼 문제 → 나머지 순서로 고르고, 쉬운 문제부터, 5지선다 보기 순서도 섞어요.
- **🔁 같은 내용, 다른 문제 세트**: 편집 화면의 클로드 상자에서 고르면, 이미 있는 문제와 겹치지 않는 새 세트를 만드는 지시문이 나와요. 가져오면 "세트 2, 3…"으로 쌓여서 퀴즈에 섞여 나와요.
- **🃏 낱말 카드로 문제 자동 만들기**: 카드마다 "뜻 고르기", "낱말 고르기" 문제가 생겨요 (카드 3개 이상).
- 클로드 지시문을 복사하기 전에 **문항 수 · 난이도(쉬움 위주/골고루/도전 위주) · 문제 유형**을 고를 수 있어요. 학생은 퀴즈를 시작할 때 쉬움/보통/도전 문제만 고를 수도 있어요.
- 🔊 읽어 주기 버튼을 한 번 더 누르면 **⏹ 멈춰요**. 읽는 동안 화면 왼쪽 아래 **"그만 읽기"** 버튼도 나와요.
- ⚠️ 이 기능이 생기기 전에 Supabase를 설정했다면 [`supabase/update-05-groups-balance.sql`](supabase/update-05-groups-balance.sql)을 SQL Editor에서 **한 번** 실행해 주세요. (업데이트 2·3·4를 먼저)

## 5-1. 🪙 코인 · 🧑‍🎨 아바타 · 🛍️ 상점

- 학생은 처음 로그인할 때 **얼굴형·피부색·눈·입·머리 모양·머리색**을 골라 캐릭터를 만들어요 (무료).
- **🧑‍🎨 꾸미기**: 전신 캐릭터에 옷·하의·신발·모자·안경·손에 드는 물건·배경·펫을 입혀요. 프로필에는 상반신 사진이 보여요.
- **🛍️ 상점**: 코인으로 아이템을 사요. 물건을 누르면 먼저 **입어 볼 수** 있고, 좋은 아이템은 **필요 레벨**이 있어요.
- 코인 얻기: 복습 보기 +1, 처음 맞힘 +2, 오답 극복 +3, 다시 맞힘 +1, 퀴즈 완주 +5(만점 +10), 출석 +3, 레벨업 +20, **선생님 칭찬 코인**
- **🎁 칭찬 코인**: 선생님 화면 → 학생 카드 → "칭찬 코인 주기" (이유를 고르면 학생 기록에 보여요. 잘못 줬으면 − 숫자로 돌려받기)
- 처음 시작할 때 학생마다 **50코인**, 이미 레벨이 오른 학생은 레벨당 20코인을 더 받아요.

## 5-2. ⚔️ RPG 장비 · 능력치

- 장비 칸: **모자·투구, 갑옷, 무기·소품(오른손), 방패(왼손), 장신구(목걸이·날개 등)** — 옷 위에 겹쳐 입어요.
- 아이템마다 능력치가 있어요: ⚔️ 공격 · 🛡️ 방어 · ❤️ 체력 · 🍀 행운, 등급은 일반 / 희귀(파랑) / 영웅(보라) / 전설(주황).
- 내 능력치 = 기본값 + **스탯 포인트 투자** + 장비. 레벨업마다 스탯 포인트 3개를 받아 꾸미기·내 정보 화면에서 직접 투자해요.
- **전투력** = 공격×3 + 방어×2 + 체력 + 행운×2 (3단계 보드게임에서 사용할 예정)
- 얼굴은 동글동글한 캐릭터 스타일로, 눈 9 · 눈썹 5(+색 6) · 코 4(+색 5) · 입 8 · 볼 3가지 중에서 골라요.
- 상점 전용: 💇 머리 모양 5(똥머리·웨이브·땋은 머리·아프로·모히칸), 🎨 머리색 5(민트·은빛·불꽃·무지개·우주), 👀 눈 4(하트·별빛·고양이·만화)
- 모자·투구를 쓰면 모자 위로 머리카락이 삐져나오지 않게 잘라서 그려요.

- ⚔️ 몬스터를 만나면 전투: **5지선다를 맞히면 공격(1분)**, **OX를 맞히면 방어(30초)**. 문제는 그동안 올린 수업의 문제에서 나와요 (풀이 기록에도 남아요).
  - 내 공격 피해 = 4 + 공격력×2 − 적 방어 / 방어를 맞히면 (방어력+2)만큼, 틀리면 방어력의 1/3만큼 막아요 (턴마다 새 방패).
  - 장비·레벨을 그 지역에 맞추면 일반 몬스터 1방, 💀 엘리트 3~4방, 👑 보스 5~6방이 되게 맞췄어요.
- 🍀 행운: 크리티컬(1.5배 피해) 5%+행운×1%(최대 30%), 보상 1.5배 5%+행운×0.8%(최대 25%), 주사위 다시 굴리기 행운×1%(최대 15%).
- 🎁 보물 상자(코인·물약·주사위 티켓), ⚠️ 함정(체력 −20%), ⛲ 쉼터(체력 회복 + 저장), 🏝️ 무인도(더블이 나오면 바로 탈출, 아니면 한 번 쉬기).
- 몬스터 보상: 일반 경험치 3+지역 / 코인 3+지역, 엘리트는 물약·주사위 티켓, 보스를 물리치면 다음 월드로 (새싹 숲 → 어둠 동굴 → 유령의 성 → 더 강한 월드…).
- 쓰러지면 코인 5%(최대 30)와 지금 레벨 안의 경험치 5%를 잃고 마지막 쉼터에서 다시 시작해요 (레벨은 안 내려가요). 체력은 매일 다시 가득 차요.
- 선생님 현황판의 학생 카드에 지금 몇 번째 월드인지 보여요.

## 6. 알아 두면 좋은 것

- **Supabase 무료 플랜은 1주일 동안 아무도 접속하지 않으면 일시정지**됩니다. 방학 뒤에는 Supabase 대시보드에서 **Restore project**를 눌러 주세요. (데이터는 그대로예요.)
- 무료 저장 공간: 데이터베이스 500MB, 파일 1GB. 판서는 자동으로 줄여서(약 100~300KB/장) 저장합니다.
- 학생 비밀번호가 같아서 서로의 계정에 들어갈 수는 있어요. 대신 실명 등 민감한 정보는 저장하지 않는 구조입니다.
- 수업 모드: ← → 키(또는 와콤 펜 버튼)로 넘기고, Enter로 정답 보기, Esc로 나가기.
